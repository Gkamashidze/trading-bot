# Walk-Forward Backtest Reports

Honest out-of-sample evidence for the baseline strategies. Generated by
`scripts/run_walk_forward.py` on real BTC/USDT 1h data (2022–2026, 39,407 bars).

## Bottom line (2026-07-05)

**Neither baseline strategy has a demonstrated edge.** Over 4 years of
out-of-sample data, with parameters tuned only on preceding train windows and
realistic taker fees + slippage, both strategies **lose to buy-and-hold** on
return *and* on risk-adjusted return (Sharpe):

| Strategy | OOS return | Sharpe | Max DD | Trades | vs Buy&Hold |
|---|---|---|---|---|---|
| **Buy & hold BTC** | **+192.6%** | **0.80** | −53.7% | 1 | — |
| SMA crossover | +59.7% | 0.52 | −50.9% | 232 | ❌ −132.8 pts |
| RSI mean-reversion | +11.0% | 0.25 | −46.1% | 140 | ❌ −181.6 pts |

## What this means

- **These strategies are NOT ready for real money.** Trading them would very
  likely underperform simply holding BTC — after fees, materially so
  (SMA paid **$7,493** in fees on a $10k account across 232 trades).
- This matches expectations: SMA crossover and RSI mean-reversion are textbook
  **reference baselines**, not alpha. The earlier paper-trading Sharpe of 6–8
  was a fill-model artifact (paper fills at signal price ⇒ zero modelled
  slippage), not real performance.
- The **value delivered here is the evidence layer**, not the strategies: a
  buyer/operator can now trust that the system measures performance honestly and
  refuses to curve-fit. Real edge requires new strategies (see the regime-aware
  work in `docs/STRATEGY_ROADMAP.md`), each of which must clear this same
  walk-forward bar before paper → micro-live promotion.

## Methodology (no look-ahead, no curve-fitting)

1. **Rolling walk-forward.** Train window ≈ 180 days, test window ≈ 30 days,
   rolled forward across the whole history (48 windows).
2. **In-sample tuning only.** On each train window the strategy parameters are
   grid-searched for best in-sample Sharpe (with a ≥5-trade floor). Those
   parameters are then applied **only** to the next, unseen test window.
3. **Continuous OOS execution.** Every test window's signals are concatenated and
   executed once through the existing `RealisticFillModel` (0.1% taker fee +
   spread/slippage), so fees and slippage compound continuously.
4. **Honest benchmark.** Buy-and-hold over the identical out-of-sample span, one
   entry fee. Sharpe/CAGR annualised for hourly bars (8,760 periods/year).

## Reproduce

```bash
python scripts/download_backtest_data.py    # BTC/USDT 1h → data/raw/ (gitignored)
python scripts/run_walk_forward.py          # regenerates every report here
```

Raw price data is intentionally not committed (regenerated on demand); only the
reports are versioned.
